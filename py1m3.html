Python Essentials 1: Module 3 Complete Exam Key

Question 1

An operator able to check whether two values are equal is coded as:

==
Explanation: Remember that the == operator compares two arguments and checks if they are equal.
Question 2

The value eventually assigned to x is equal to:

x = 1 x = x == x
True
Explanation: The == operator is more prominent in the operator hierarchy than the = operator. Therefore, the operation on the right is evaluated before the one on the left.
Question 3

How many stars (*) will the following snippet send to the console?

i = 0 while i <= 3: i += 2 print("*")
two
Explanation:
  • The i variable is assigned the integer value of 0.
  • The while loop compares if 0 <= 3, and since it is True, the loop is entered.
  • The i variable is incremented by 2, and a first star is printed on the console.
  • The while loop now compares if 2 <= 3, and since it is True, the loop is entered.
  • The variable i is incremented by 2, and a second star is printed on the console.
  • The while loop now compares if 4 <= 3, and since it is False, the loop is no longer executed.
Question 4

How many stars (*) will the following snippet send to the console?

i = 0 while i <= 5: i += 1 if i % 2 == 0: break print("*")
one
Explanation:
  • The i variable is assigned the integer value of 0.
  • The while loop is entered. i is incremented by 1 (becomes 1).
  • The operation 1 % 2 is evaluated to 1. Since 1 == 0 is False, the if conditional is not executed.
  • A star is printed on the console.
  • In the next iteration, i becomes 2. 2 % 2 == 0 is True, so the break statement terminates the loop.
Question 5

How many hashes (#) will the following snippet send to the console?

for i in range(1): print("#") else: print("#")
two
Explanation:
  • The for loop begins using the variable i as counter, it begins in 0 and stops before 1, so a single iteration is performed.
  • A first # is printed on the console.
  • After exiting the loop normally, the else statement is executed.
  • A second # is printed on the console.
Question 6

How many hashes (#) will the following snippet send to the console?

var = 0 while var < 6: var += 1 if var % 2 == 0: continue print("#")
three
Explanation:
  • The var variable starts at 0 and loops up to 5.
  • For even numbers (2, 4, 6), the continue statement skips the print command.
  • For odd numbers (1, 3, 5), it executes the print block, printing a total of three hashes.
Question 7

How many hashes (#) will the following snippet send to the console?

var = 1 while var < 10: print("#") var = var << 1
four
Explanation:
  • var = 1: Loop prints 1st #, shifts left to 2.
  • var = 2: Loop prints 2nd #, shifts left to 4.
  • var = 4: Loop prints 3rd #, shifts left to 8.
  • var = 8: Loop prints 4th #, shifts left to 16. Loop terminates as 16 < 10 is False.
Question 8

What value will be assigned to the x variable?

z = 10 y = 0 x = y < z and z > y or y > z and z < y
True
Explanation:
  • y < z is True and z > y is True → True and True returns True.
  • y > z is False and z < y is False → False and False returns False.
  • Finally, True or False returns True.
Question 9

What is the output of the following snippet?

a = 1 b = 0 c = a & b d = a | b e = a ^ b print(c + d + e)
2
Explanation:
  • c = a & b → 1 & 0 = 0
  • d = a | b → 1 | 0 = 1
  • e = a ^ b → 1 ^ 0 = 1
  • Sum: 0 + 1 + 1 = 2.
Question 10

What is the output of the following snippet?

my_list = [3, 1, -2] print(my_list[my_list[-1]])
1
Explanation:
  • my_list[-1] picks the last element, which is -2.
  • Then, my_list[-2] picks the second to last element, which is 1.
Question 11

What is the output of the following snippet?

my_list = [1, 2, 3, 4] print(my_list[-3:-2])
[2]
Explanation: Using negative indices (-3:-2), the elements from the third-last position to before the second-last position are selected. Therefore, only the element 2 is extracted into a new sublist.
Question 12

The second assignment:

vals = [0, 1, 2] vals[0], vals[2] = vals[2], vals[0]
reverses the list
Explanation: Using positive indices, the value in position 0 is swapped with the element in position 2. The elements are now in this order: 2, 1, 0. Therefore, the list has been reversed.
Question 13

After execution of the following snippet, the sum of all vals elements will be equal to:

vals = [0, 1, 2] vals.insert(0, 1) del vals[1]
4
Explanation:
  • The list starts as [0, 1, 2].
  • vals.insert(0, 1) inserts 1 at index 0 → [1, 0, 1, 2].
  • del vals[1] deletes the item at index 1 → [1, 1, 2].
  • Sum: 1 + 1 + 2 = 4.
Question 14

Take a look at the snippet, and choose the true statements: (Select two answers)

nums = [1, 2, 3] vals = nums del vals[1:2]
nums and vals are of the same length
AND
nums and vals refer to the same list
Explanation: The assignment vals = nums does not create a copy; both variables point to the exact same list in memory. Modifying one affects the other, keeping their length equal.
Question 15

Which of the following sentences are true? (Select two answers)

nums = [1, 2, 3] vals = nums[-1:-2]
nums is longer than vals
AND
nums and vals are two different lists
Explanation: Slicing constructs a brand new list. Since the slice range [-1:-2] is invalid when moving in the default positive direction, it results in an empty list [] or a sequence shorter than the original, making nums longer.
Question 16

What is the output of the following snippet?

my_list_1 = [1, 2, 3] my_list_2 = [] for v in my_list_1: my_list_2.insert(0, v) print(my_list_2)
[3, 2, 1]
Explanation: Every item from my_list_1 is prepended to the start (index 0) of my_list_2 consecutively, effectively reversing the collection.
Question 17

What is the output of the following snippet?

my_list = [1, 2, 3] for v in range(len(my_list)): my_list.insert(1, my_list[v]) print(my_list)
[1, 1, 1, 1, 2, 3]
Explanation: The loop updates exactly 3 times. In each iteration, it reads the current index v and inserts that value into index 1, progressively inserting '1's into the list.
Question 18

How many elements does the my_list list contain?

my_list = [i for i in range(-1, 2)]
three
Explanation: The expression range(-1, 2) generates values starting from -1 up to (but excluding) 2, which are: -1, 0, 1. That results in exactly three items.
Question 19

What is the output of the following snippet?

t = [[3-i for i in range(3)] for j in range(3)] s = 0 for i in range(3): s += t[i][i] print(s)
6
Explanation: The matrix evaluates to [[3, 2, 1], [3, 2, 1], [3, 2, 1]]. Summing up diagonal elements t[0][0] + t[1][1] + t[2][2] returns 3 + 2 + 1 = 6.
Question 20

What is the output of the following snippet?

my_list = [[0, 1, 2, 3] for i in range(2)] print(my_list[2][0])
the snippet will cause a runtime error
Explanation: The list comprehension builds a nested structure containing only two sublists (index 0 and index 1). Querying index [2] results in an IndexError.
